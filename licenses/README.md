# Procedência dos textos

`OCCT/LICENSE_LGPL_21.txt` e `OCCT/OCCT_LGPL_EXCEPTION.txt` são cópias sem alteração dos arquivos fornecidos em `usr/share/licenses/opencascade/` pelo pacote OCCT 7.9.3 usado na validação local. Os scripts de Linux e Windows incluem este diretório nos pacotes.

O OCCT mantém suas fontes em <https://github.com/Open-Cascade-SAS/OCCT>, com os mesmos textos na distribuição de fontes. Estes arquivos não mudam a licença MIT do código próprio do 3dnator. Outros recursos e dependências mantêm seus avisos próprios; ver [THIRD_PARTY.md](../THIRD_PARTY.md).
